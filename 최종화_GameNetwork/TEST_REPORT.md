### 전송량 조건 비교

방법: 수신 측 `benchstart N` → 송신 측 `bench N` → 수신 측 `benchstop` (`DESIGN.md` 3.8)

| 항목 | 100개 | 10,000개 |
| --- | ---: | ---: |
| 요청 메시지 수 | 100 | 10,000 |
| 송신 완료 호출 수 | 100 | 10,000 |
| 송신 오류 수 | 0 | 0 |
| 수신 데이터그램 수 | 100 | 10,000 |
| 측정 종료 시점의 관측 누락 수 | 0 | 0 |
| 송신 소요 시간 | 24.00 ms | 145.73 ms |
| 수신 측 측정 구간 시간 | 57,391.57 ms | 15,000.10 ms |
| 측정 후 A가 반영한 B 위치·번호 | | |
| 측정 후 B가 반영한 A 위치·번호 | | |

해석: 두 조건 모두 송신 완료 수와 수신 데이터그램 수가 요청 수와 일치했고 오류·관측 누락은 0이었습니다. 수신 측 측정 시간에는 명령 입력·터미널 전환 시간이 포함되므로 네트워크 지연으로 해석할 수 없습니다. 관측 누락 수는 측정 종료 시점까지 도착하지 않은 메시지 수이며 확정된 손실을 뜻하지 않습니다. UDP는 전달을 보장하지 않으므로 이 결과는 로컬 환경에서 관측한 값에 한정됩니다.
